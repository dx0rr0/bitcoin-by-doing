# Sources and versions

[Course outline](README.md)

These sessions contain original exercises. The links help check concepts and look up operations; they are not solutions to copy.

## Bitcoin Core

- [Official distribution](https://bitcoincore.org/en/download/): choose and verify a version during session 0.
- [Regtest](https://developer.bitcoin.org/examples/testing.html#regtest-mode): the environment and controlled block generation. Includes examples from older versions.
- [Core 30.0 RPC reference](https://bitcoincore.org/en/doc/30.0.0/): a versioned reference for the first guides. This does not mean 30.0 is the latest version or the one you must install.
- [Bitcoin Core repository](https://github.com/bitcoin/bitcoin): documentation and code for each version.

Before using a parameter, consult `help` on the installed node. Record the version actually used in your notes. Investigate differences from the website rather than changing things blindly.

## Revisiting a concept

- [Learn Me a Bitcoin](https://learnmeabitcoin.com/): introductory explanations, technical material, and an explorer by Greg Walker.
- [Programming Bitcoin, Jimmy Song](https://github.com/jimmysong/programmingbitcoin): a reference for going deeper into the pieces you implement. You do not need to follow it in order during this course.
