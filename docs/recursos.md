# Fuentes y versiones

[Recorrido](README.md)

Las sesiones son ejercicios propios. Los enlaces sirven para contrastar conceptos y consultar operaciones, no como soluciones que haya que copiar.

## Bitcoin Core

- [Distribución oficial](https://bitcoincore.org/en/download/): elegir y verificar una versión durante la sesión 0.
- [Regtest](https://developer.bitcoin.org/examples/testing.html#regtest-mode): explicación del entorno y generación controlada de bloques. Contiene ejemplos de versiones antiguas.
- [Referencia RPC de Core 30.0](https://bitcoincore.org/en/doc/30.0.0/): referencia versionada para las primeras guías. No significa que 30.0 sea la versión más reciente ni la que deba instalarse.
- [Repositorio de Bitcoin Core](https://github.com/bitcoin/bitcoin): documentación y código correspondientes a cada versión.

Antes de usar un parámetro, consultar `help` en el nodo instalado. En las notas se registrará la versión realmente usada; una diferencia con la web se investigará, no se corregirá a ciegas.

## Para volver a un concepto

- [Learn Me a Bitcoin](https://learnmeabitcoin.com/): explicaciones introductorias, sección técnica y explorador del autor, Greg Walker.
- [Programming Bitcoin, Jimmy Song](https://github.com/jimmysong/programmingbitcoin): referencia para profundizar en las piezas implementadas. No es necesario seguirlo en orden durante este taller.

## Para preparar contribuciones

- [Proceso de Bitcoin Core](https://github.com/bitcoin/bitcoin/blob/master/CONTRIBUTING.md).
- [Tests funcionales](https://github.com/bitcoin/bitcoin/blob/master/test/functional/README.md).
- [Política de uso de IA](https://github.com/bitcoin/bitcoin/blob/master/doc/AI_POLICY.md).

Las páginas y reglas de los proyectos pueden cambiar. Se volverán a consultar al comenzar la instalación o una contribución.
